# 莲境 · 手势粒子莲花

> 八万颗粒子，一池会开合的莲。

「莲境」把粒子花园的方向推向另一种花：纯黑背景、细密发光粒子、四层尖瓣莲花。握拳时收拢为尖顶花苞，手掌张开时外圈花瓣先展开，完全张开时八万颗粒子铺成一朵完整莲花；手掌移动时整朵花同步跟随。

## 运行

仓库根目录启动静态服务，访问 `/versions/lotus/`：

```bash
cd <项目根目录>
python -m http.server 8080
# http://localhost:8080/versions/lotus/
```

首次克隆仓库时如果 `vendor/` 与 `models/` 为空，先在仓库根目录执行：

```bash
bash scripts/fetch-assets.sh
```

## 操作

- 点击「启用手势」，允许摄像头；取景框只显示手部骨架。
- 握拳收拢，手掌张开盛放；手掌在画面中移动，莲花整体平移跟随。
- 手动：拖动「开合」、在画面上上下拖动、按 `1/2/3`、空格、`P`（切换配色）、`C/H/R`。
- 配色：粉紫 / 蓝紫 / 暖金，三套共用同一亮度和饱和度。
- 数量：默认 80,000；桌面 20,000–120,000，手机 20,000–60,000，步进 5,000；实时重建但不改变开合。

## 形态

| 开合 | 形态 | 画面 |
| --- | --- | --- |
| 0–24% | 含苞 | 花瓣螺旋合拢成尖顶花苞，光点收紧 |
| 24–72% | 初绽 | 外圈花瓣先翻开，内圈仍护住花心 |
| 72–100% | 绽放 | 四层尖瓣完全展开，边缘高光连成薄光 |

## 实现

- 12 / 10 / 8 / 6 四层花瓣，配合 2,400 个莲蓬粒子、1,400 个花丝粒子和 500 个暖色芯光，默认总量 80,000。
- 每个粒子存三套配色；切换配色只改 `uPalette`，不重建几何。
- 花瓣、花苞两套位置在顶点着色器内插值；花苞阶段缩小点径，保留尖顶和层叠缝。
- 手掌位置驱动整组平移，不给每个粒子做 CPU 弹簧，保证 80k 下仍稳定。
- 单 draw call；自适应像素比；低帧率自动降清晰度。

更完整的创作说明见 [`creative/BRIEF.md`](./creative/BRIEF.md)。

## 浏览器与降级

- 需要 WebGL 2；无 WebGL 时显示静态莲花线稿与说明。
- 摄像头不可用会保持手动模式；不显示摄像头画面。
- 支持 `prefers-reduced-motion`。
- 手机默认 40,000 粒子，避免中低端设备发热。
